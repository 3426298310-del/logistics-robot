# Logistics Robot — Final Mechanical Model

HKU DASE7503 Robotic Systems Integration · Group 8

## 最终完整建模（2026-11-03）

本版本根据整体(16).zip发布，替换原beta CAD。包含整车装配、轮组、电机安装结构、电子设备固定结构、抬升连杆与滑槽、舵机齿轮齿条机构、顶部承托平台及连接件。共43个CAD文件。

个人贡献：独立重建整车SolidWorks机械模型，负责机械结构与硬件集成。运动控制、视觉、雷达识别和路径规划由其他组员负责；厂家设备为第三方参考模型。

## 打开模型

完整下载仓库并解压，使用兼容版本的SolidWorks打开 `cad/solidworks/整体.SLDASM`，保留该目录下全部零件和子装配。项目此前使用SolidWorks 2026；本次上传未重新检查文件版本、异机引用解析、装配干涉或运动学。

- `cad/solidworks/`：最终模型原文件。
- `docs/file-manifest.json`：文件大小及SHA-256校验。
- `archive/beta-2026-10-09/`：旧预览、旧加工文件与旧审查，仅作历史记录，不代表最终版加工数据。

“最终版”指本次提交的完整建模版本，不代表实车承载、限高和功能已通过验证。加工前应使用最终模型重新核对尺寸、材料、公差并导出加工文件。beta原模型保留于Git历史。

不包含课程PDF、私人简历或网络配置密码。第三方模型权利与贡献边界见 `docs/sources-and-scope.md`。
